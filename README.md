# Scribe — versions

Images disque de **Scribe**, l'outil macOS qui commente les scripts FileMaker,
et son flux de mise à jour (`appcast.xml`, lu par l'app).

**Installer** : télécharger le `Scribe-x.y.dmg` de la dernière Release, l'ouvrir,
glisser Scribe dans Applications. L'app est signée et notarisée ; elle se met
ensuite à jour toute seule (menu Scribe › Rechercher les mises à jour…).

macOS 26 requis. Le code source est privé.
